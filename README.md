# AI Security, Privacy & Auditing — University Coursework

Academic projects developed during the **Security, Legal and Ethical Aspects of Intelligent Systems** course, part of the BSc in Artificial Intelligence at the University of A Coruña (UDC).

The assignments explore security vulnerabilities, privacy-preserving machine learning and risk assessment in AI systems.

## Projects

### P1 — Adversarial Machine Learning

Experiments involving attacks against image classification models, including:

- Adversarial examples using FGSM and PGD.
- Data poisoning and backdoor attacks on pretrained CNNs.
- Evaluation of attack effectiveness and model robustness.
- Security challenges involving large language models.

**Technologies:** Python, PyTorch, Adversarial Robustness Toolbox.

### P2 — Federated Learning & Differential Privacy

Experiments investigating the security and privacy of distributed machine learning.

- Federated training of convolutional neural networks using FedAvg.
- Model poisoning through malicious client updates.
- Byzantine-robust aggregation using Trimmed Mean.
- Membership inference attacks against trained models.
- Differential privacy experiments using DP-SGD and Opacus.

**Technologies:** Python, PyTorch, Opacus, Adversarial Robustness Toolbox.

### P3 — AI Systems Auditing

Academic risk assessment of intelligent systems, covering:

- System architecture and operational context.
- Security, privacy and ethical risks.
- Regulatory considerations.
- Risk mitigation, controls and deployment recommendations.

### Tutored Project — LLM Security & Guardrails

Proof of concept exploring the security of LLM-based applications.

- Simulated vulnerable conversational agent.
- Prompt injection and information disclosure scenarios.
- Defensive mechanisms using NVIDIA NeMo Guardrails.
- Comparative evaluation of protected and unprotected configurations.

**Technologies:** Python, Google Gemini API, NeMo Guardrails.

## Repository Contents

Each project includes its corresponding implementation and/or technical report.

The original assignment instructions were provided by the course instructors.

## Academic Context

These projects were completed collaboratively as university coursework.

The repository preserves the original academic implementations and experiments. They are intended to demonstrate the concepts explored during the course rather than represent production-ready systems.

Some experimental results and methodologies may require further validation before being applied outside the academic setting.
